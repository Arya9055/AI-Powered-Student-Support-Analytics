# AI-Powered Student Support Analytics

An independent Business Analytics project developed during my MBA in Business Analytics at Golden Gate University.

This project explores how generative AI, SQL, Excel, and Power BI can improve student-support operations by analyzing student inquiries, identifying urgency, classifying issues, and supporting smarter routing.

## Business Problem

Student inquiries may involve registration, course access, academic advising, technical support, financial questions, and other student services.

Manually reading, categorizing, prioritizing, and routing every inquiry can increase response time and create inconsistent routing.

The goal of this project was to explore how data analytics and AI could improve this process.

## Tools Used

- Excel
- SQL
- Power BI
- Generative AI / ChatGPT
- Prompt Engineering
- Business Process Mapping

## What I Did

- Identified the business problem and stakeholders
- Defined business requirements
- Created AS-IS and TO-BE process flows
- Built a simulated dataset with 5,000 student-support inquiries
- Used Excel and SQL for data analysis
- Designed a Power BI-style dashboard
- Used generative AI to classify inquiry intent, category, urgency, and root cause
- Refined prompts and validated AI outputs
- Proposed a future Agentic AI workflow for smart routing and support automation

## Key KPIs

- Total inquiries
- Average response time
- Average resolution time
- Misrouting rate
- Repeat-contact rate
- Student satisfaction
- Inquiry categories
- Urgency levels
- Root-cause trends

## AI Use Case

Generative AI was used to analyze unstructured student messages and convert them into structured outputs such as:

- Intent
- Category
- Urgency
- Summary
- Root-cause theme

This helped connect text-based student inquiries with operational data for deeper analysis.

## Key Learning

Traditional analytics helped identify **what was happening**, while generative AI helped understand **why it was happening**.

The future Agentic AI concept showed how the organization could potentially take action on those insights through smarter routing and workflow automation.
